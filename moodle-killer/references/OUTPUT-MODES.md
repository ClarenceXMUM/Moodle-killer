# 5 种推送风格：实际长什么样

换风格：`mk output heartbeat|silent|digest|urgent|full`
**想先看效果再决定？** `mk output --demo` —— 一条命令把 5 种风格的实际输出并排打出来（不联网、不推送）。
一次推送最多几行由 `output.max_lines` 控制（默认 5；`full` 不受限）。

下面每条都是**真实输出格式**（`[类型] 课程: 内容`），只是内容举例。

---

## 1. `heartbeat` — 天天报到（默认）

**没事时**：照报一句，让你知道它还活着。

```
[Moodle] 已扫5课 无新内容 · 下次 09/10 08:30
```

**有事时**：更新 + 收尾行。

```
[新作业] 数学分析: 第4章练习 截止 09/20 23:59 (剩11天21小时47分)
[附件] 数据结构: Lecture07-BTree.pdf 已下载
[Moodle] 已扫5课 · 下次 09/10 08:30
```

- 适合：想确认「它到底跑没跑」的人
- 代价：每天至少一条，哪怕没事
- **线上默认就是它**——静默 ≠ 故障，没消息会让人以为坏了

---

## 2. `silent` — 安静，只报事

**没事时**：完全不说话（脚本输出空，调度器不推送）。

**有事时**：只报更新，**不加收尾行**。

```
[新作业] 数学分析: 第4章练习 截止 09/20 23:59 (剩11天21小时47分)
```

- 适合：嫌吵、只想有事时被叫的人
- 风险：它坏了你也看不出来 —— 建议偶尔 `mk status` 确认

---

## 3. `digest` — 每天一份汇总

**没事时**：也有日报头。

```
[Moodle 日报 09/09] 扫了 5 门课，0 条更新
· 今天没有新内容
```

**有事时**：日报头 + 条目。

```
[Moodle 日报 09/09] 扫了 5 门课，2 条更新
[新作业] 数学分析: 第4章练习 截止 09/20 23:59 (剩11天21小时47分)
[成绩] 数据结构: Quiz2 已出分 87/100
```

- 适合：每天固定时间看一条，喜欢「有头有尾」
- 特点：永远有内容（没更新也告诉你扫过了）

---

## 4. `urgent` — 只报紧急

**没事时**：完全不说话。

**有事时**：只报 **24 小时内截止** 和 **新出的成绩**。

```
[新作业] 操作系统: Lab5 报告 截止 09/10 10:00 (剩7小时12分)
[成绩] 数据结构: Quiz2 已出分 87/100
```

- 适合：平时不想被打扰，只要「快到期了」和「出分了」
- 注意：超过 24h 的截止日期**不会**出现在这里 —— 想提前知道就换 `heartbeat`

---

## 5. `full` — 全都报

**没事时**：空。

**有事时**：全部条目，不受 `max_lines` 限制。

```
[新作业] 数学分析: 第4章练习 截止 09/20 23:59 (剩11天21小时47分)
[新作业] 操作系统: Lab5 报告 截止 09/10 10:00 (剩7小时12分)
[成绩] 数据结构: Quiz2 已出分 87/100
[公告] 线性代数: 周五停课一次
[附件] 数据结构: Lecture07-BTree.pdf 已下载
```

- 适合：想一眼看全部，不怕长
- 代价：一天更新多的时候会很长

---

## 选哪个？一句话决策

| 你的心态 | 选它 |
|---|---|
| 想确认它每天都在跑 | `heartbeat` |
| 别烦我，有事才说话 | `silent` |
| 每天固定看一条汇总 | `digest` |
| 只要快到期 + 出分 | `urgent` |
| 全都告诉我 | `full` |

---

## 暂停 ≠ 换风格

- 想「这几天别推」→ `mk pause`（脚本照跑，只是不推）；`mk resume` 恢复
- 想「永远只报紧急」→ `mk output urgent`（不用暂停）
